# BUG-001: Preferred Language Update Fails with Permission Error

**Application:** BookStack Demo  
**Module:** User Profile / Account Settings  
**Test Date:** 31 October 2026  
**Browser:** Google Chrome  
**Operating System:** Windows  
**Severity:** Medium (Provisional)  
**Status:** Observed – Requires Verification

## 1. Bug Description

When an Admin user attempts to change the Preferred Language from the account settings, the application displays a permission error instead of saving the selected language.

## 2. Preconditions

- User is logged in as Admin.
- Account settings are accessible.

## 3. Steps to Reproduce

1. Open the BookStack Demo application.
2. Log in as Admin.
3. Navigate to My Account.
4. Find the Preferred Language option.
5. Select `Deutsch (Sie)`.
6. Click Save.
7. Observe the application response.

## 4. Expected Result

The application should save the selected language successfully and display the updated preference.

## 5. Actual Result

The application displays:

`You do not have permission to access the requested page.`

The user is redirected to the Dashboard, and the language preference remains unchanged.

## 6. Severity

**Medium (Provisional)**

The issue prevents the user from updating an account preference. Severity requires further verification.

## 7. Evidence

- Screenshot 1: Preferred Language selection.
- Screenshot 2: Permission Error after saving.

Both screenshots are stored in the `Bug Report` folder.

## 8. Impact

Users may be unable to change their preferred language through the account settings.

## 9. Notes and Limitations

This behavior was observed in the public BookStack Demo environment. The demo may restrict user account updates. Therefore, it is not yet confirmed as an application defect.

Further testing in an unrestricted environment is required.

## 10. Recommendation

Verify whether the permission restriction is intentional. If language updates are permitted, investigate the save operation and authorization handling.
